# iLogic-Tools
iLogic tools and examples

We’ve made an abbreviated copy of some of our standard functions in the “Viewrail
Functions.vb” file. If used with our Demo Rule ilogic, it will work without issues. We have noticed
that Inventor will throw errors if the “iLogicVb “ wrapper is not used somewhere in the rule. In
our base rule we have the logger entries to time the rule execution. If you remove this, make
sure you add some line using the iLogicVb wrapper.
